## Features

- **Customer Management**: Add, edit, and manage customer information
- **Product/Service Catalog**: Manage products and services with pricing
- **Invoice Generation**: Create professional invoices with tax calculations
- **Payment Tracking**: Record and track customer payments
- **Reports & Analytics**: Generate financial reports
- **Multi-user Support**: Role-based access control
- **PDF Export**: Export invoices as PDF documents
- **Email Notifications**: Send invoices via email
- **Dashboard**: Real-time statistics and charts
- **Multi-currency Support**: Handle multiple currencies
